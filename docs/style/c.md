# C Style

## Code Formatting

Code formatting shall conform to the clang-format configuration found in the root of each repository. If no clang-format configuration is present, assume no specific formatting is expected. Exceptions can be made if necessary by using the clang-format meta comments.

## Variable & Function Naming

- Lowercase.
- Snake case.
- Prefer longer verbose names over contractions and meaningless names.
    - An exception for `for` loops is to use `i` then `j` for counter variables.

## Type Naming

Defined on a per-project basis.

## Macro Naming

- Every letter capitalized.
- Snake case.
